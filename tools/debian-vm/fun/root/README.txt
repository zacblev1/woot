
  You're in /root, the boss's home folder. Normally nobody gets in here.

  With great power comes great responsibility. ...Except here, where
  nothing is real and a reload fixes everything. So if you've always
  wondered what this famous "never do this" command actually does:

      sudo rm -rf --no-preserve-root /

  It deletes EVERYTHING, including the programs it needs to keep
  running. Try running ls afterwards. Then reload the page.

  (Do NOT do this on a real computer. That's the whole joke.)
