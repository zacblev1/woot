<task type="auto">
  <name>Task 1: Install Vitest and testing dependencies</name>
  <files>package.json</files>
  <action>
Install Vitest and related testing packages as dev dependencies:

```bash
npm install -D vitest @vitest/coverage-v8 happy-dom @testing-library/react @testing-library/user-event @testing-library/jest-dom
```

Why these packages:
- vitest: Test runner, ESM-native, fast
- @vitest/coverage-v8: Coverage reporting
- happy-dom: Lightweight DOM implementation (faster than jsdom for React 19)
- @testing-library/react: Component testing utilities
- @testing-library/user-event: Realistic user interaction simulation
- @testing-library/jest-dom: Custom matchers (toBeInTheDocument, toHaveClass, etc.)

Add test script to package.json scripts:
```json
"test": "vitest",
"test:coverage": "vitest run --coverage"
```
  </action>
  <verify>
Run `npm test -- --run` and verify Vitest starts (will show "no tests found" which is expected)
  </verify>
  <done>
package.json has vitest in devDependencies and "test" script runs Vitest
  </done>
</task>

<task type="auto">
  <name>Task 2: Create Vitest configuration</name>
  <files>vitest.config.ts, vitest.setup.ts</files>
  <action>
Create vitest.config.ts at project root:

```typescript
import { defineConfig } from 'vitest/config'
import react from '@vitejs/plugin-react'
import path from 'path'

export default defineConfig({
  plugins: [react()],
  test: {
    environment: 'happy-dom',
    setupFiles: ['./vitest.setup.ts'],
    include: ['**/*.test.{ts,tsx}'],
    globals: true,
    css: false,
    coverage: {
      provider: 'v8',
      reporter: ['text', 'json', 'html'],
      exclude: [
        'node_modules/',
        '.next/',
        '*.config.*',
        'vitest.setup.ts',
      ],
    },
  },
  resolve: {
    alias: {
      '@': path.resolve(__dirname, './'),
    },
  },
})
```

Create vitest.setup.ts at project root:

```typescript
import '@testing-library/jest-dom/vitest'
```

Note: Using `@testing-library/jest-dom/vitest` (not `/extend-expect`) for proper Vitest integration.

Also install @vitejs/plugin-react:
```bash
npm install -D @vitejs/plugin-react
```
