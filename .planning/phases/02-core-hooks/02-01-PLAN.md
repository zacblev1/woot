**Interface (export as type):**
```typescript
export interface UseTerminalHistoryReturn {
  history: string[]
  historyIndex: number
  add: (command: string) => void
  clear: () => void
  navigateUp: () => string | null
  navigateDown: () => string | null
  resetNavigation: () => void
}
```

**Implementation details:**
- Use `useState<string[]>([])` for history array
- Use `useState<number>(-1)` for historyIndex (-1 means not navigating)
- `add(command)`: Append to history, reset index to -1, skip empty strings
- `clear()`: Reset history to [], reset index to -1
- `navigateUp()`: If history empty, return null. If index is -1, set to length-1. Otherwise decrement (clamped to 0). Return command at new index.
- `navigateDown()`: If index is -1, return null. Increment index. If >= length, reset to -1 and return null. Otherwise return command at new index.
- `resetNavigation()`: Set index to -1

**Important:**
- Wrap all action functions in `useCallback` with correct dependencies
- navigateUp/navigateDown depend on [history, historyIndex]
- add/clear have no dependencies (use functional updates)
- Do NOT include 'use client' directive - hooks don't need it
